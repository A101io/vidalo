# Vidalo keys: what goes where (25 Oct 2026)

Two places for every key:

- **Local:** one line `NAME=value` in `/Users/a101/Vidalo/.env` (open in TextEdit now). No spaces around `=`, no quotes.
- **Live site:** Cloudflare → Workers & Pages → the Worker in the last column → Settings → Variables and Secrets → **Add** → Type **Secret** → Name and Value → **Deploy**.
  - vidalo-web: https://dash.cloudflare.com/37c9615a0d7d9629154eca03d7de59a6/workers/services/view/vidalo-web/production/settings
  - vidalo-worker: https://dash.cloudflare.com/37c9615a0d7d9629154eca03d7de59a6/workers/services/view/vidalo-worker/production/settings

Tell Claude the **names** you set, never the values.
