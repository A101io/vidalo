# A-04 — Export without secrets, streamed; "Koppeling met Google verbreken"

*lane: A (Opus) · estimate: 5 h · depends on: C-00*

## Goal
The download holds every data category and no token, secret or other person's address, and
completes for a long history within Worker limits; the owner can disconnect Google, which
revokes and deletes the token. Serves AC-5 (a), (e); AC-7 (the export part).

## Contract
From `02-architecture.md` "Export" and "Google disconnect", ADR-0006:
- `core/shared/my-data.ts`: `export const CHANNEL_META_EXPORT_KEYS: readonly string[];`
  `export function exportChannel(c: Channel): Omit<Channel, "meta"> & { meta: Record<string, unknown> };`
  `exportMyData` uses it.
- `core/shared/export-stream.ts`:
  `export function streamMyData(db: Db, businessId: string, opts: { signedInAs: string; now?: Date }): ReadableStream<Uint8Array>;`
- Db: `listSamplesForRuns`, `listEventsPage`, `deleteChannel` (shared contract §2).
- `GET /api/account/export?business=<uuid>`: 401 / 404 / streamed attachment as in the
  interface contract; `account.exported` event; `cache-control: no-store`.
- `core/shared/google-revoke.ts`:
  `export async function revokeGoogleToken(token: string, fetchImpl?: typeof fetch): Promise<void>;` (POST `https://oauth2.googleapis.com/revoke`, form body `token=…`; 200 or 400 `invalid_token` = done; else throw)
  `export async function disconnectGoogle(db: Db, businessId: string, revoke: (t: string) => Promise<void>, reason: "owner" | "churn" | "purge"): Promise<{ disconnected: number }>;`
  In mock mode (`!env.hasGoogle`) the web passes a revoke that records the call in an event.
- `/app/google`: "Koppeling met Google verbreken" (a form with hidden `business`, one
  confirming button), `disconnectGoogle(form)` → `requireOwnerOf` → `/app/google?ontkoppeld=1`;
  ownership proof stays. Copy in `copy.accountSecurity.google`.
- The "Je gegevens" download link on `/app/account` carries `?business=<active id>`.
- F-020: `sendOwnerPhoneCode`, `checkOwnerPhoneCode` take the form's `business` and pass
  `requireOwnerOf`; `/app/google` forms carry it. `GET /api/google/start?business=`: a
  business the login is a member of, or else the existing claim path for an unowned
  business (proof by Google decides); never the cookie. `/api/google/callback`: unchanged
  logic (the state cookie binds the business), reviewed for the membership rule.

Consumes from lane B: `requireOwnerOf`, `isMember` (C-00 stubs suffice).

## Tests
- `export-secrets.test.ts`: a business with a gbp channel `meta { refreshToken: "rt-<random>",
  accessToken: "at-<random>", expiresAt, apiSecret: "s-<random>", pendingDiff: {...} }`, an
  event naming another address; the full streamed body (read to the end) contains none of
  the three random strings nor the other address, and does contain `pendingDiff`. Same for
  `exportMyData`.
- Paging: 36 runs × 50 samples on MemDb and PgDb → every sample id appears once; the number
  of `listSamplesForRuns` calls is `ceil(36 / 6)`.
- `google-revoke.test.ts` with a fake fetch: 200 → done; 400 `invalid_token` → done; 503 →
  throws and the channel is not deleted; `disconnectGoogle` deletes only that business's gbp
  channel (control business keeps its own) and leaves `ownerVerifiedAt`.
- Route: export for a non-member business id → 404, nothing logged on that business.
- Timing: the paging test's 36-run PgDb seed streamed end to end under 30 s on `verify:pg`,
  recorded in `04-build.md`; the delivery-lead repeats it after merge with B-03's full seed
  (`scripts/perf/seed-history.mts`) on a local production build.
