# A-02 — Sign-in confirmed by POST and recorded; lifetime; sign out here or everywhere; sign-in list

*lane: A (Opus) · estimate: 8 h · depends on: C-00, A-01 (same lane)*

## Goal
A scanner's GET of the mail link uses nothing up; every sign-in is recorded; a session ends
after 30 days unused or 90 days; "Uitloggen" ends this browser, "Overal uitloggen" every
browser; `/app/account` lists the last 10 sign-ins. Serves AC-3 (c)–(f), AC-4 (d).

## Contract
From `02-architecture.md` "Session" and "Sign-in link" (scanner-safe part), shared contract §2
(session Db methods) and §3 (`0018_auth_sessions.sql`):
- `core/shared/session-life.ts`:
  `export const IDLE_DAYS = 30, MAX_DAYS = 90, FRESH_MINUTES = 15;`
  `export type SessionVerdict = "ok" | "missing" | "ended" | "idle" | "max_age";`
  `export function sessionVerdict(row: SignInRow | null, now: Date): SessionVerdict;`
  `export function isFreshSignIn(s: { signedInAt: string }, now: Date): boolean;`
  `export function uaFamily(userAgent: string | null): { browser: BrowserFamily; os: OsFamily };`
- Db: `recordSignIn` (also sets `business.last_active_at` where `owner_user_id = userId`, F-012; the column comes with 0019 in A-05 — until then the method skips that update), `getSignIn`, `touchSignIn`, `endSignIns`, `listSignIns`, `deleteSignIns`
  in `types.ts`, MemDb, PgDb (shared contract §2).
- `getSession()` as specified (claims → row → verdict → end + local sign-out, or touch);
  React `cache()`; mock auth carries `sid` and `signedInAt` in `vidalo_mock_session` and
  records a row too.
- `GET /auth/confirm` page + `confirmSignInAction` (ADR-0003); `/auth/callback` → 303
  `/auth/confirm?<query>`; `lib/auth-confirm.ts` and `app/auth/confirm/route.ts` removed.
- `POST /auth/uitloggen`: `scope: "local"`, `endSignIns(…, "signed_out", { sessionId })`.
  (The Origin check is added in A-03.)
- `signOutEverywhere()` server action; `/inloggen?uitgelogd=overal` and `?fout=verlopen`
  states with their sentences.
- Every form on `/app/account` that posts to a changing action (incl. lane B's `checkNow` and
  the moved `setLanguage`) carries `<input type="hidden" name="business">` (F-020).
- `/app/account` section "Inloggen" gets the sign-in list and "Overal uitloggen" (one
  button, secondary style; the page keeps one primary button). Markup per the AC-8 rules in
  `02-architecture.md` (status line `role="status"`, list as `<ol>`, current device in words).
- Copy under `copy.accountSecurity` (`confirmPage`, `signIns`, `signOutEverywhere`,
  `expired`, `signedOutEverywhere`), NL and EN.

Consumes from lane B: `Session` shape (fixed), `getOwnedBusiness` alias. Nothing else.
