# B-02 — "Rapporten": every report in one place; the owner's own reports never expire for them

*lane: B (Sonnet) · estimate: 6 h · depends on: C-00*

## Goal
A new "Rapporten" item lists every finished check of the active business newest first with
date, kind in words, dot colour and "n van m antwoorden klopten", each linking to its report;
the owner's free report older than 30 days opens for the owner and still shows not-found to
anyone else. Serves AC-1.

## Contract
From `02-architecture.md` "Data model 0017", "Report archive", ADR-0007:
- `supabase/migrations/0017_run_summary.sql`: `scan_run.summary jsonb`, CHECK
  `scan_run_summary_shape`, index `scan_run_archive_idx`.
- In `packages/core/src/db/owner-area.ts`:
  `export interface RunSummary { v: 1; stip: "red" | "orange" | "green" | "grey"; answered: number; correct: number; snapshot: ScanSnapshot }`
  `export interface ArchiveRow { id: string; kind: ScanKind; status: ScanRun["status"]; createdAt: string; summary: RunSummary | null }`
  `export function saveRunSummary(db: Db, scanRunId: string, summary: RunSummary): Promise<void>;`
  `export function listReportArchive(db: Db, businessId: string, opts: { limit: number; before?: string }): Promise<{ rows: ArchiveRow[]; next: string | null }>;`
  `export function runSummaries(db: Db, businessId: string, limit: number): Promise<ArchiveRow[]>;` (done, non-recheck, with summary; used by B-03)
  MemDb keeps summaries in a module `WeakMap<MemDb, Map<string, RunSummary>>`.
- `export function summarizeRun(report: ScanReport, snapshot: ScanSnapshot): RunSummary;` —
  `answered`/`correct` are the numbers the report heading shows (`apps/web/lib/report.ts`
  counts; move the counting into this function and have the report call it, or prove equality
  by test).
- `packages/core/src/scanner/index.ts`: after the run is marked `done`, build report and
  snapshot and `saveRunSummary`; a failure there logs and does not fail the scan.
- `scripts/backfill-run-summaries.mts`: every done run without a summary, in batches.
- `packages/core/src/shared/report-access.ts`:
  `export function reportVisible(r: { kind: ScanKind; checkedAt: string; businessId: string }, viewerBusinessIds: readonly string[], now: Date): boolean;`
- `apps/web/app/r/[id]/page.tsx`: `load()` uses `reportVisible` with the ids of
  `listMyBusinesses(session)` (empty when signed out); `ownerOf` uses the same list.
- `apps/web/app/app/rapporten/page.tsx`: rows as AC-1 (date, kind word, dot `aria-hidden` plus
  the colour's meaning in words, "n van m antwoorden klopten"); queued/running/failed in words,
  no link; "Oudere rapporten" link with `?voor=<cursor>` when `next`; empty state.
- `apps/web/app/app/layout.tsx`: nav item "Rapporten" after "Voortgang".
- Copy `copy.ownerArea.archive` (`nav`, `h1`, `intro`, `kind.{free,baseline,monthly,ondemand}`,
  `state.{queued,running,failed}`, `counts(correct, answered)`, `older`, `empty`), NL and EN.
- `demo-owner-area.ts`: the demo owner's main business gets a free check from 45 days ago, a
  baseline, three monthly checks, one on-demand check, one recheck and one failed check.

  login's ids, not to `[]`; 29 days old → visible to all; a paid kind 400 days old → visible

  heading's numbers; `scan_run_summary_shape` refuses a summary without `answered` (PgDb).

  business's runs never appear.

  kind words and counts, the failed one without a link; the 45-day-old free report opens for
