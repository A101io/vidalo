# FE-02 — The report of an online business: competition block and "Gecontroleerd als"

*lane: frontend · estimate: 5 h · depends on: BE-01 (types only)*

## Goal
An online business's report leads with who AI names next to it, in counts only, shows what it was
checked as, and never names a town; local reports keep "Wie AI wel noemt" as it is. Serves AC-5,
AC-6 (display), AC-8 (competition block), AC-A10, Q5, Q8.

## Contract
Consumed from `ScanReport` (`@vidalo/core/types`, BE-01):
```ts
report.profile?: { mode: "door" | "visit" | "online"; offer; audience; category; source } | null   // null = older report, treat as door
report.recommendations?: {
  promptId: string; prompt: string; intent: RecommendationIntent | null; pool: "core" | "bank";
  probe: string | null; answers: number; named: number;
  others: { name: string; answers: number }[];          // top 5
  sources: { host: string; url: string; answers: number }[];
  family: "rec_town" | "rec_category" | "alternative";
  quotes: { text: string; engine: Engine }[];            // ≤ 3, only rec_category / alternative
}[]
// a finding with factKey "identity", subject "kind": wrongValue "other", correctValue "same"
// asked[] cells with factKey "identity", subject "kind" are the "wat doet X" question
```
Build in `apps/web/lib/report.ts` (`buildReportView`), new fields on `ReportView`:
```ts
checkedAs: string | null;            // "Gecontroleerd als: aanbieder van achtergrondmuziek voor hotels en horeca, online"; every mode when profile is known
competition: null | {                // only when profile.mode === "online"
  summary: string;                   // "Genoemd in 4 van 30 antwoorden" over all rec_category + alternative rows
  questions: { question: string; you: string; others: { name: string; times: string }[]; quotes: { text: string; engine: string }[] }[];
  note: string;                      // we count whether you are named, never a position; naming does not change the colour
};
```
- One entry per `rec_category` and `alternative` row, in report order; `you` = "Genoemd in n van m
  antwoorden" (also when n = 0, then the names follow: never an empty block); up to 5 others with
  "n van m"; up to 3 quotes, each with its engine label.
- No score, no "%", no rank or "plek", no "#1", no judgement of a competitor anywhere in the block.
- Online: the h1 and header show the name without the town (Q8); question lines for about-findings
  and "Alle antwoorden" use town-free wording (`apps/web/lib/questions.ts`: `questionFor` gains an
  `online` flag; `identity`/`kind` reads "Wat doet {naam}?" and its wrong line "beschreven als een
  ander soort bedrijf"); "Wie AI wel noemt" is not shown (there are no `rec_town` rows); the plan
  panel's "1 vestiging" reads "1 bedrijf" (Q5).
- Local (door/visit): unchanged apart from the `checkedAs` line.
- The block sits next to the dot near the top (A5); exact placement and look are for the design
  gate; status colours only in dots.

Copy (NL + EN, under `copy.result.competition` and `copy.result.checkedAs`): h2, `summary(n, m)`,
`you(n, m)`, `times(n, m)`, `quoteBy(engine)`, `note`, mode words for `checkedAs`, the identity:kind
lines, "1 bedrijf". Banned in all of them: score, %, plek, ranking, share of voice, GEO, AEO, LLM,
prompt, platform, zichtbaarheid, and any promise that Vidalo makes AI name the business.
