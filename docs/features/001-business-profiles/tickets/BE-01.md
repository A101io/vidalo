`packages/core/src/db/types.ts`:
```ts
interface BusinessRecord { profileAuto: BusinessProfile | null; profileOwner: BusinessProfile | null; }
interface ScanRunCreate { profile?: BusinessProfile | null; }
interface QuestionUseInput { scanRunId: string; category: string; mode: ProfileMode; templateKey: string; templateNl: string; family: QuestionFamily; intent: string | null; asked: number; usable: number; }
interface LibraryRow { category: string; mode: ProfileMode; templateKey: string; templateNl: string; family: QuestionFamily; intent: string | null; asked: number; usable: number; }
interface Db {
  setAutoProfile(businessId: string, profile: BusinessProfile): Promise<void>;   // profile_auto only
  setOwnerProfile(businessId: string, profile: BusinessProfile): Promise<void>;  // profile_owner only
  recordQuestionUse(rows: QuestionUseInput[]): Promise<void>;                   // insert, conflict on (scanRunId, templateKey) ignored
  questionLibrary(filter?: { category?: string; mode?: ProfileMode }): Promise<LibraryRow[]>; // sums
}
```
Small pure functions other lanes import, implemented in full here so nobody waits:
- `prompts/slots.ts`: `sanitizeSlot(raw: string, slot: "name" | "category" | "audience" | "offer" | "competitor"): string | null`.
  Rules (ADR-0003): Unicode NFC; refuse (null) when the raw text holds `<`, `>`, `://`, `www.`, a
  domain-shaped token (`/\b[\p{L}\d-]+\.[a-z]{2,}\b/iu`, allowed only in `name`) or an instruction
  word (negeer, vergeet, instructie, systeem, prompt, opdracht, ignore, disregard, forget,
  instruction, system, assistant, "je bent", "you are", "act as"; whole words, case-insensitive);
  then keep only letters, digits, spaces and `&'-.`; collapse spaces; trim; refuse when fewer than
  two letters remain; cut at a word boundary to name 80, category 60, audience 80, offer 120,
  competitor 60.
- `scanner/understand.ts`: `effectiveProfile(b)` and
  `parseOwnerProfile(fields, current)` → `{ok:true, profile}` with `source:"owner"`, `basis:["owner"]`,
  `grounded:true`, `confidence:"high"`, competitors and website kept from `current`; or
  `{ok:false, field, reason}`: `required` (empty), `refused` (`sanitizeSlot` null; mode not one of
  the three), `too_long` (raw longer than the limit before cleaning). All four fields are required.

MemDb implements the four methods in full (`upsertBusiness` never touches the two profile fields;
`questionLibrary` sums the array). PgDb gets the signatures with `throw new Error("BE-02")` bodies
only if needed to compile; BE-02 replaces them.
