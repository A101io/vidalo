# BE-02 — Migration 0015 and PgDb

*lane: backend · estimate: 3 h · depends on: BE-01*

## Goal
The data model of `02-architecture.md` in Postgres, with every rule named there as a constraint,
and PgDb behaving like MemDb. Serves AC-A1, AC-A7, AC-A8 and the owner-correction rule.

## Contract
`supabase/migrations/0015_business_profiles.sql` (check `git ls-tree origin/main supabase/migrations`
first; if 0015 is taken, use the next number):

```sql
alter table business add column if not exists profile_auto jsonb, add column if not exists profile_owner jsonb;
alter table scan_run add column if not exists profile jsonb;
alter table prompt add column if not exists template_key text check (template_key is null or char_length(template_key) <= 80);
-- one shape check per column: business_profile_auto_shape, business_profile_owner_shape, scan_run_profile_shape
--   x is null or (
--     x->>'mode' in ('door','visit','online')
--     and char_length(coalesce(x->>'offer','')) <= 120 and char_length(coalesce(x->>'audience','')) <= 80
--     and char_length(coalesce(x->>'category','')) <= 60
--     and jsonb_typeof(coalesce(x->'competitors','[]'::jsonb)) = 'array' and jsonb_array_length(coalesce(x->'competitors','[]'::jsonb)) <= 3
--     and coalesce(x->>'offer','') || coalesce(x->>'audience','') || coalesce(x->>'category','') !~ '[<>{}\[\]"`\\/@#$%^*=|~;:]'
--   )
create table if not exists question_use (
  id bigserial primary key,
  scan_run_id uuid references scan_run(id) on delete set null,
  category text not null check (char_length(category) between 1 and 60),
  mode text not null check (mode in ('door','visit','online')),
  template_key text not null check (char_length(template_key) between 1 and 80),
  template_nl text not null check (char_length(template_nl) between 1 and 300),
  family text not null check (family in ('existence','hours','address','payment','phone','what','website','rec_town','rec_category','alternative','other')),
  intent text,
  asked int not null check (asked >= 0),
  usable int not null check (usable >= 0 and usable <= asked),
  at timestamptz not null default now(),
  unique (scan_run_id, template_key)
);
create index if not exists question_use_category_mode_idx on question_use (category, mode);
alter table question_use enable row level security;
revoke all on table question_use from anon, authenticated;
create or replace view question_library with (security_invoker = true) as
  select category, mode, template_key, max(template_nl) as template_nl, family, max(intent) as intent,
         sum(asked)::int as asked, sum(usable)::int as usable,
         round(sum(usable)::numeric / nullif(sum(asked), 0), 2) as usable_share
  from question_use group by category, mode, template_key, family;
revoke all on question_library from anon, authenticated;
```
Comment the file the way `0009_waitlist.sql` is commented (why RLS without policies).

PgDb: the four `Db` methods from BE-01; `getBusiness` maps `profile_auto`/`profile_owner`;
`upsertBusiness` never writes them; `createScanRun` writes `profile`; `getScanRun`/`listScanRuns`
read it; `insertPrompts`/`listPrompts` carry `template_key`; `deleteBusiness` needs no change
(`on delete set null`).
