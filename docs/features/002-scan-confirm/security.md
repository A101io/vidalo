# 002 scan-confirm: security review (phase 4)

Reviewed 11 Nov 2026 against the uncommitted change on `claude/scan-mail-confirm` (diff + untracked
files). Read-only on code. No phase-1 security checklist was written for this feature, so the
baseline is `docs/process/checklists/security.md` and `_OS/playbook/SECURITY.md`; the
foreseeability cap therefore has no list to apply against (see SEC-01 note).

## Verdict

**Blocked by one P0 (SEC-01).** The link is single-use only for requests that arrive one after
another. Parallel presses of one link each start a free check, and the same race defeats the daily
cap and the per-visitor allowance. This is the abuse the feature exists to stop, and it is now
cheaper than before: one Turnstile solve plus one mailbox, where every check used to need its own
solve. Everything else is P1 or lower.

## Checked and holding

- **Token format and entropy.** The token is `<businessId>.<24 random bytes, base64url>`: 192 bits, and the 32-character secret is enforced by regex (`scan-confirm.ts:43,51`). Only `sha256(token)` goes into the pending and used events. Lookup compares hashes, which gives a timing side channel nothing useful. The token is length-capped at 200 before splitting. Probe: `abc_123.FiFk…p6`, length 40, parses back to `abc_123`.
- **Replay, sequential.** A second press after the first one finished goes to the stored `to` (`route.ts:30`). A cap refusal leaves the link usable, as the brief intends. Expiry is 24 h from the pending event (`findPending`). The used check runs before the pending lookup, and `order by at desc` keeps the used marker inside any window that holds the request. (The parallel case is SEC-01.)
- **Open redirect.** Every redirect is `${env.baseUrl}${localizeHref(path)}`. A path such as `//evil` would become `https://vidalo.ai//evil`, which stays on the host. `found.to` is only ever written by the server (`/r/<id>`, `/scan/<token>`). No route lets a client choose an event type (grep of `logEvent(` in `apps/web`).
- **Referer.** `/scan/bevestigen` sets `referrer: no-referrer`, and the site sends `Referrer-Policy: strict-origin-when-cross-origin` (`next.config.ts`). The POST body carries the token and the 303 lands on a token-free URL. The remaining leak is analytics (SEC-04).
- **Mock-only `?link=`.** It is shown only when `VIDALO_MOCK=1` (`scan/mail/page.tsx:20`). The same flag makes engines mock (`scanner/engines/index.ts:29-31`) and stops Resend (`reporter/mail.ts:31-33`). Only the `preview` env sets it, and preview has no database and no queue (`apps/web/wrangler.jsonc:57-59`). Production and staging set `VIDALO_MOCK=0`. The link cannot appear while engines are real.
- **The address never travels in a URL.** It goes in the form post, then in the signed cookie, then in the pending event. `/scan/mail` and `/scan/druk?mail=1` carry nothing.
- **Enumeration.** `/scan/mail` is the same page for every address. `?mail=1` shows only that this address or connection hit its own daily count, which tells nobody anything about accounts.
- **The gate still applies.** `requestBehindGate` covers both POSTs (`api/scan/route.ts:50`, `bevestigen/route.ts:27`), and the middleware gates `/scan/*` pages. Pre-existing and outside this change: the preview cookie is the literal value `1` (`gate-state.ts:18`, `core/shared/gate.ts`), so anyone who sets `vidalo_preview=1` passes the gate. In production (`VIDALO_COMING_SOON=1`) the gate is therefore not a spend control. This feature does not rely on it as one.
- **Caps before the Places lookup.** `freeCheckRefusal` runs after Turnstile and before `resolveBusiness` (`api/scan/route.ts:65-71`), so AC-8 holds. The confirmation-mail caps are check-then-insert like the others, but each `/api/scan` post needs its own single-use Turnstile token, so a burst there costs one solve per mail.
- **Secrets.** The change adds no secret, no new env var and no client-side key. No bundle was built for this review; nothing in the diff reaches `NEXT_PUBLIC_*`.
- **Output encoding.** The business name and `t` are rendered through React (escaped); the mail escapes HTML (`reporter/layout.ts:52`).
