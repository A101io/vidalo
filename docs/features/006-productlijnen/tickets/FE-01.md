# FE-01 — /app/productlijnen: the list, the nav, the English path, the access banner

*lane: frontend · estimate: 4 h · depends on: BE-01 (types, MemDb, seed)*

## Goal
The owner sees every product line with, per market, one dot per AI system, the open error count
and "genoemd als aanrader n van m keer"; an owner without access sees why. Serves AC1 (view), AC3.

## Contract
Consumed (BE-01): `ProductLine`, `LineScope`, `Db.listProductLines`, `runSummaries(db, businessId, 1, { productLineId, market })`
(`summary.engineStips` via `summary.snapshot.engineStips`, `summary.stip`, `summary.recommend`),
`Db.listFindings(businessId, ["open","fixing","recheck"], { productLineId })`,
`productLineAccess(business, session.userId)`, `PRODUCT_LINE_LIMITS.lines`.

Files:
- `apps/web/lib/product-lines.ts` (new): `loadProductLines(business): Promise<LineListItem[]>` with
  `LineListItem = { line: ProductLine; markets: { market: string; checkedAt: string | null; stip: Stip | null; engineStips: EngineStip[]; openErrors: number; named: { named: number; answers: number } | null }[] }`.
  Reads through the service handle after `requireOwner`, as `owner-data.ts` does.
- `apps/web/app/app/productlijnen/page.tsx` (new): `requireOwner("/app/productlijnen")`. Per line a
  `Section`/`Row` card: name, category, "Niet meer leverbaar" pill for discontinued, then one row per
  market: market name (`countryName(code, lang)`), one `Dot` per AI system with the engine label as
  text, "n fouten open", "Genoemd als aanrader: n van m keer" (or "Nog niet gecontroleerd"), link to
  `/app/productlijnen/<id>?markt=<code>`. Above the list: the access banner when
  `productLineAccess` fails (one sentence per reason), else the primary button "Productlijn
  toevoegen" (→ `?nieuw=1`, the form is FE-02's) unless the active count is at the limit
  ("Je hebt het maximum van n productlijnen"; no price). Empty state for no lines.
  `?opgeslagen`, `?status`, `?fout` messages in an `aria-live` region.
- `apps/web/app/app/layout.tsx`: nav item "Productlijnen" (`/app/productlijnen`) when the business
  has lines or `productLineAccess` passes.
- `apps/web/lib/lang-paths.ts`: nested segment map `app/productlijnen ↔ app/product-lines` in
  `fromUrl` and `localizeHref`; test both directions and that `/en/app/voortgang` is unchanged.
- Copy `copy.productLines` (NL `index.ts`, EN `en.ts`): `nav`, `h1`, `intro`, `add`, `empty`,
  `discontinued`, `notChecked`, `openErrors(n)`, `named(n, m)`, `limit(n)`, `access: Record<LineAccessRefusal, string>`,
  `saved`, `statusSaved`, `errors` (shared with FE-02).

Design G, on main's `OwnerUi` components (`Section`, `Row`, `Dot`, `BlueLink`, `QuietLink`,
`SmallButton`) so the corporate branch's status pass applies when it merges. Never a score, a
percentage or a position. One primary button per view. Status in text as well as colour.
