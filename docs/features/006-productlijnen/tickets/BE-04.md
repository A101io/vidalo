# BE-04 — Scanning a line: the Facts view, the four keys, the runScan branch

*lane: backend · estimate: 6 h · depends on: BE-01, BE-03*

## Goal
`runScan({ businessId, kind, productLineId, market })` asks a line's questions per market and
produces a `ScanReport`, findings, a summary and a snapshot exactly as a business run does.
Serves AC2, AC3 (data), AC4 (data), AC7.

## Contract
`02-architecture.md`, "Scanner" (the seven differences, the question table, the judging table) and
ADR-0010.

Files:
- `packages/core/src/scanner/line.ts` (new): `lineFacts(business, facts, version, market, now?)`.
  Certificates get `valid = validUntil == null || validUntil >= scan date (YYYY-MM-DD, Europe/Amsterdam)`.
- `packages/core/src/scanner/index.ts`: `RunScanOptions.productLineId`, `.market`; the branch at the
  seven named places; `buildReport` and `buildSnapshot` rebuild a line run from
  `getProductLineVersion(run.productLineId, run.productLineVersion)` and scoped prompts; summary saved
  for line runs as for business runs (not for rechecks).
- `packages/core/src/scanner/normalize.ts`: `factValue` and `valuesMatch` for `spec`, `certificate`,
  `outlet`, `successor` reading `facts.productLine`.
- `packages/core/src/scanner/extract.ts`: rules extraction for the four probes (spec value after the
  label; `yesNo` for certificates; outlet names from list items, bold names and cited hosts;
  successor via `mentionsBusiness`); LLM extraction prompt gains the four keys (values normalised the
  same way); `mentionsBusiness` treats `facts.productLine` like an online profile (no place needed);
  `detectOtherEntity` returns false when `facts.productLine` is set.
- `packages/core/src/scanner/engines/mock.ts`: deterministic answers for line prompts (by the
  prompt's `category` and probe; `inferProbe` gains the four kinds for text-only calls), with the
  same wrong-pair rate: a wrong spec value, an outlet not in the list, "nee" on a valid certificate,
  an old name as successor, and named/not named for recommendations.
- `packages/core/src/scanner/compare.ts` needs no change beyond what the keys bring; if a change is needed,
  write why in `04-build.md`.
