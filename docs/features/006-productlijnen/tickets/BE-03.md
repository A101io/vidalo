# BE-03 — The questions a line is asked, NL and EN

*lane: backend · estimate: 3 h · depends on: BE-01*

## Goal
Code-held templates for the five kinds of line question, filled only with sanitised slots, in
`scanLang(market)`, stored per (line, market). Serves AC2.

## Contract
- `packages/core/src/prompts/line.ts` (Dutch) and `line.en.ts` (English): `LINE_TEMPLATES` with the
  keys, texts, kinds, categories, probes and criteria of the question table in
  `02-architecture.md`, "Scanner". Same keys in the same order in both files.
- `generateLinePrompts(version: ProductLineVersion, market: string, brand: string): PromptInput[]`:
  - language `scanLang(market)`; `{land}`/`{country}` from `countryName(market, lang)`;
  - one `line.rec.use` per use case, else one `line.rec.quality`; one `line.spec` per spec; one
    `line.cert` per certificate (expired ones too: asking is how "still certified" is caught); one
    `line.outlet` when the market has at least one outlet; one `line.successor` per replaced name;
  - `{Welke}` / `{de beste}` from `welkFor` / `deBesteFor`; spec labels through `welkFor` as well
    ("Welke drukklasse", "Welk gewicht"); English needs no article logic;
  - " van {merk}" / " by {brand}" only when `normalizeName(version.name)` does not contain
    `normalizeName(brand)`;
  - every slot through `slotValue()`; a refused slot skips that template (never asked with a hole);
  - `templateKey` = the template key; `kind`, `category`, `probes: [probe]`, `criterium`, `pool: "core"`.
- `loadLinePrompts(db, businessId, version, market, kind, promptIds?)`: with `promptIds`, the stored
  scoped prompts with those ids; else the generated set, inserting the missing ones with
  `insertPrompts(businessId, missing, { productLineId, market })`, returned in template order by text
  (as the online path of `loadPrompts`). Stored prompts of older versions stay and are not asked.
- `packages/core/test/line-prompts-en.test.ts`: NL and EN templates in step (keys, order, slots).

## Done when
- [ ] Tests: the seed's Speltbrood v2 gives for NL: 2 rec, 2 spec, 1 cert, 1 outlet, 1 successor (7), Dutch, "Welk gewicht heeft Haarlems Speltbrood van Bakkerij De Vries?"; for BE the same 7 in English with "in Belgium"
- [ ] A line name containing the brand gets no " van {merk}"
- [ ] A use case refused by the sanitiser is skipped; no question contains `{` or `}`
- [ ] Calling `loadLinePrompts` twice inserts nothing the second time; a new version adds only new texts
- [ ] `pnpm -r typecheck && pnpm -r test` green; tests shown to fail without the change
- [ ] No secret, no personal data in logs
