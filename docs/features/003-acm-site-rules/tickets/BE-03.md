# BE-03 — Vidalo Monthly is priced with its start fee everywhere; the checkout consent is pinned

*lane: backend (packages/core, apps/web routes and lib) · estimate: 0.5 d · depends on: none · complex: no · contract: `../02-architecture.md` §3, §6, §10*

## Goal
Every surface outside the price card that names Vidalo Monthly's price also names the €149
start, and the B2B checkout consent cannot be loosened silently. Serves AC-11 (F-002), AC-12.

## Acceptance criteria (from `01-brief.md`)
- **AC-11** (extended by F-002) — Given any place that states the Vidalo Monthly price to someone who has not paid Vidalo Scan (the assistant, `/llms.txt`, Vidalo's own facts page, the JSON-LD offer), when read, then it says €149 once + €49 per month, excl. btw.
- **AC-12** — Given the checkout, when a session is created, then `consent_collection.terms_of_service` is required and the custom text says Vidalo is for businesses (already so: `route.ts:121-125`); a test pins both.

## Contract
- `packages/core/src/chat/index.ts:103`: the price reply names Vidalo Monthly as `€149 eenmalig + €49 per maand` (use `copy.landing.prijs.monitor.total` from BE-01 when merged; until then the same text from `PRICES`). Line 39 already does it for the knowledge text.
- `apps/web/app/llms.txt/route.ts:34`: `- Vidalo Monthly: €149 eenmalig (Vidalo Scan) + €49 per maand, excl. btw, maandelijks opzegbaar.` built from `PRICES`.
- `packages/core/src/shared/own.ts:70`: the Monthly row's `unit` says `per maand, excl. btw; start met Vidalo Scan (€149 eenmalig)`; keep `amount: PRICES.monitorEurPerMonth`. Check `own.test.ts` and the facts-page render snapshot.
- `apps/web/lib/seo.tsx:94`: the Monthly `Offer` gets a `description` naming the start fee (`"Start met Vidalo Scan, €149 eenmalig, excl. btw"`); the price stays 49.00 with its `UnitPriceSpecification` (schema.org has no clean compound fee here; a description is honest and cheap).
- `packages/core/test/price-surfaces.test.ts` (new): the chat price reply (NL, EN), the `/llms.txt` body (imported as a function or read as source), and `OWN_FACTS.prices` (`own.ts:68-72`) each contain `149` wherever they contain the Monthly price. Control: revert `chat/index.ts:103` → red.
- `packages/core/test/checkout-consent.test.ts` (new): reads `apps/web/app/api/checkout/route.ts` as text and asserts `consent_collection: { terms_of_service: "required" }`, `custom_text` with `consentSubmit(` and `consentAccept(`, and that the no-Stripe branch tests `env.mock` (pins F-009 after BE-02; mark that assertion `it.todo` until BE-02 merges if this ticket lands first, and say so in the PR); asserts `copy.checkout.consentSubmit("t","p")` contains `niet voor consumenten` and `en.checkout.consentSubmit` contains `not for consumers`. Control: `"required"` → `"none"` turns it red.
